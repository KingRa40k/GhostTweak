## ⚡ Быстрый старт за 2 минуты (Quick Start)

Чтобы мгновенно запустить проект на вашем компьютере:

```bash
# 1. Запуск десктопного приложения в режиме разработчика:
npm install
npm run tauri dev

# 2. Сборка готового релиза (.exe) в один клик:
Запустите файл build.bat в корне проекта

# 3. Запуск промо-сайта в браузере:
cd website
npm install
npm run dev
# Откройте http://localhost:3000
```

Для входа в приложение и тестирования функционала используйте мастер-ключ:
```text
GHOST-VIP-PRO-2026
```

## 💎 Комплектация передаваемого проекта

Вместе с проектом вы получаете:
1. **100% исходный код ядра на Rust (`src-tauri/`)**: прямой Win32 API, таймер ядра 0.5 мс, безопасная очистка кэшей шейдеров DirectX, NVIDIA, AMD, управление службами.
2. **100% исходный код фронтенда (`src/`)**: React 19, TypeScript, кастомная неоновая дизайн-система с переключением 4 цветовых тем и мультиязычностью (RU/EN).
3. **Маркетинговый сайт (`website/`)**: Next.js 15, адаптивный интерактивный макет приложения, таблица сравнения с аналогами, мультиязычность.
4. **Готовые скомпилированные дистрибутивы (`website/public/downloads/`)**:
   * `GhostTweak_Setup_v1.0.0.exe` (NSIS-установщик)
   * `GhostTweak_Portable.exe` (портативная версия 4.8 МБ)
   * `GhostTweak_v1.0.0.msi` (MSI-пакет)
5. **Систему лицензирования с привязкой к материнской плате (HWID)** и набор готовых пожизненных ключей.
6. **Автоматическую систему бэкапов реестра (`.reg`)** с защитой от сбоев.
