# GhostTweak — Руководство покупателя и владельца проекта

Поздравляем с приобретением проекта **GhostTweak**! Этот документ содержит исчерпывающее техническое руководство по сборке, настройке, смене контактов и генерации лицензионных ключей.

---

## 1. Архитектура проекта

Проект разделен на две независимые части:
1. **Десктопное приложение (Tauri v2 + Rust + React 19):**
   * `src-tauri/` — Нативное ядро на языке Rust. Отвечает за прямое взаимодействие с Win32 API, таймер ядра (0.5 мс), очистку кэшей, твики реестра, бэкапы и криптографическую проверку лицензий с привязкой к HWID.
   * `src/` — Пользовательский интерфейс на React 19, TypeScript и Tailwind CSS с кастомной дизайн-системой, темами оформления и мультиязычностью (RU/EN).
2. **Промо-сайт и страница продажи (Next.js 15):**
   * `website/` — Полноценный адаптивный сайт на Next.js 15 (App Router) с поддержкой локализации (RU/EN), интерактивным превью приложения, таблицей сравнения и готовыми кнопками загрузки.

## 2. Быстрый старт и локальный запуск

### Системные требования:
* **Node.js**: v18.0.0 или новее (рекомендуется v20 LTS)
* **Rust**: `rustup` с установленным toolchain `stable-x86_64-pc-windows-msvc`
* **Visual Studio Build Tools**: С компонентом *C++ build tools* для сборки нативных Win32 бинарников

### Запуск десктопного приложения в режиме разработки:
```bash
# Установка зависимостей (в корне проекта)
npm install

# Запуск в режиме живой перезагрузки (Hot Reload)
npm run tauri dev
```

### Запуск сайта локально:
```bash
cd website
npm install
npm run dev
# Сайт откроется по адресу: http://localhost:3000
```

## 3. Сборка готовых установщиков (.exe, .msi, Portable)

Сборка дистрибутивов осуществляется одной командой:
```bash
# Вариант 1 (через пакетный скрипт в корне):
build.bat

# Вариант 2 (через npm):
npm run tauri build
```

После завершения компиляции готовые файлы появятся в папках:
* **Установщик NSIS (.exe)**: `src-tauri/target/release/bundle/nsis/GhostTweak_1.0.0_x64-setup.exe`
* **Установщик Windows Installer (.msi)**: `src-tauri/target/release/bundle/msi/GhostTweak_1.0.0_x64_en-US.msi`
* **Портативная версия (.exe без установки)**: `src-tauri/target/release/ghosttweak.exe`

## 4. Управление лицензиями и ключами

Система лицензирования работает локально без обязательного внешнего сервера, используя криптографическую проверку контрольных сумм и привязку к HWID материнской платы.

### Где находятся и как редактируются ключи:
Файл ядра: [`src-tauri/src/commands/security.rs`](src-tauri/src/commands/security.rs)
* В функции `verify_native_license()` объявлен список мастер-ключей (VIP, Esports, Overclock и др.).
* Алгоритмический генератор принимает любой ключ формата `GHOST-XXXX-YYYY-ZZZZ`.
* Для привязки к вашей собственной онлайн-базе или платёжному шлюзу (Robokassa, Lava, PaySelection, Stripe): достаточно добавить HTTP-запрос к вашему API в функцию `verify_native_license` или в React-хук [`src/lib/license.ts`](src/lib/license.ts).

### Рабочие мастер-ключи для тестов:
* `GHOST-VIP-PRO-2026` — VIP пожизненный доступ
* `GHOST-FPS-BOOST-9999` — Pro Streamer лицензия
* `GHOST-MAX-PERF-ULTRA` — Overclock Edition
* `GHOST-ESPORTS-CS2-PRO` — Киберспортивное издание
* `GHOST-CYBER-WAR-9999` — Максимальный тариф

## 6. Развертывание промо-сайта на бесплатный хостинг (Vercel)

Сайт полностью оптимизирован под Vercel:
1. Зарегистрируйтесь на [Vercel](https://vercel.com) через GitHub.
2. Нажмите **«Add New Project»** и импортируйте репозиторий `GhostTweak`.
3. В графе **Root Directory** укажите `website`.
4. Нажмите **Deploy**. Через 60 секунд сайт будет доступен в сети с бесплатным SSL-сертификатом.
5. При желании в панели Vercel можно привязать собственный домен (например, `ghosttweak.ru` или `ghosttweak.com`).
