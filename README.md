# GhostTweak

Настольное приложение для Windows, предназначенное для оптимизации системы под соревновательные игры и ПК с ограниченной производительностью.

Размер исполняемого файла: **4.8 МБ** (инсталлятор NSIS: **1.58 МБ**). Приложение работает без веб-серверов в фоне и без платформы Electron.

---

## О проекте

GhostTweak устраняет микрофризы (stuttering), выравнивает график времени кадра (0.1% и 1% Low FPS), разгружает оперативную память и снижает системную задержку ввода.

В отличие от PowerShell или командных скриптов, приложение использует нативное ядро на Rust с прямыми вызовами Win32 API и безопасной работой с реестром (`winreg`). Перед внесением изменений в реестр создается резервная копия веток (`.reg`) с возможностью отката.

Репозиторий также содержит исходный код промо-сайта на **Next.js 15 (App Router)** в каталоге `website/`.

## Возможности

### 1. Оптимизация игр (CS2, Valorant, Apex, Dota 2)

Набор настроек для устранения просадок кадров на ноутбуках и процессорах с агрессивным энергосбережением:
- **Приоритет процесса (IFEO CPU Priority)**: реестровое переключение процесса игры в высокий приоритет (`CpuPriorityClass = 3`).
- **Снятие резерва CPU (`SystemResponsiveness = 0`)**: отключение резерва в 20% ресурсов процессора, который Windows по умолчанию оставляет для фоновых мультимедийных задач.
- **Отключение парковки ядер (Core Unparking)**: фиксация активного состояния всех ядер (`CPMINCORES = 100`) через Windows Powercfg, что исключает микрозадержки при выходе ядер из спящего режима.
- **Отключение Power Throttling**: снятие ограничений энергопотребления с игровых процессов.
- **Очистка Standby List ОЗУ**: выгрузка неиспользуемого дискового кэша оперативной памяти через вызов Win32 `EmptyWorkingSet`. Освобождает память перед запуском матча и предотвращает обращения к диску.
- **Параметры запуска**: генерация аргументов под фактическое количество потоков процессора (`-threads`, `-high`, `-nojoy`).
- **Конфиг autoexec.cfg**: оптимизированный файл настроек рендеринга и аудиоподсистемы для Counter-Strike 2.

### 2. Панель управления (Dashboard)

- **Быстрое переключение профилей**: режимы `[ESPORTS]`, `[AAA ИГРЫ]`, `[СТРИМ]`, `[ТИХИЙ]` в верхней части экрана.
- **Мониторинг ОЗУ**: отображение занятой и свободной памяти в реальном времени с кнопкой сброса рабочих наборов.
- **Аппаратные данные**: определение модели CPU, GPU, объема оперативной памяти и редакции Windows.
- **Пакетная оптимизация**: применение проверенного набора параметров и очистка временных файлов одной кнопкой.

### 3. Профили работы

- **Esports Competitive** (CS2, Valorant, Apex): аппаратный таймер 0.5 мс, отключение алгоритма Nagle (`TCPNoDelay = 1`), высокий приоритет сетевых прерываний DPC.
- **AAA Cinematic** (Cyberpunk 2077, GTA): приоритизация планировщика GPU, стабилизация фреймтайма и оптимизация буфера видеопамяти.
- **Streamer & Creator** (OBS, Discord, Twitch): изоляция звуковых потоков, приоритизация аппаратного кодировщика NVENC/AV1 и сетевой QoS.
- **Quiet / Work**: сбалансированный профиль с возвратом стандартного энергопотребления и интерфейсных анимаций Windows.

### 4. Очистка кэшей и диска

Удаление временных и устаревших файлов с диска:
- **Шейдерные кэши видеокарт**:
  - NVIDIA: `%LOCALAPPDATA%\NVIDIA\GLCache`, `NV_Cache`, `%LOCALAPPDATA%\D3DSCache`
  - AMD: `%LOCALAPPDATA%\AMD\DxcCache`, `DxCache`, `GLCache`
  - DirectX Shader Cache
- **Системные каталоги**: пользовательская папка `%TEMP%`, `C:\Windows\Temp`, кэш обновлений `C:\Windows\SoftwareDistribution\Download`, эскизы проводника.
- **Подсчет размера**: предварительная оценка освобождаемого пространства перед удалением.

### 5. Твики реестра и служб

- **Игровые компоненты**: отключение фонового оверлея Xbox Game Bar, службы записи Game DVR и оптимизация полноэкранного режима DWM.
- **Телеметрия**: остановка и отключение службы `DiagTrack` (Connected User Experiences and Telemetry), установка `AllowTelemetry = 0`, отключение Cortana и встроенных поисковых рекомендаций.
- **Питание и интерфейс**: активация плана электропитания «Максимальная производительность» (`SCHEME_MIN`), отключение эффектов прозрачности и ресурсоемких анимаций интерфейса.
- **Сетевой стек**: отключение задержки подтверждения TCP (`TcpAckFrequency = 1`, `TCPNoDelay = 1`), отключение индекса сетевого троттлинга (`NetworkThrottlingIndex = 0xFFFFFFFF`).

### 6. Резервные копии (Backups)

- Перед изменением параметров в реестре затронутые ветки экспортируются утилитой `reg export`.
- Файлы сохраняются в `%APPDATA%\GhostTweak\backups\`.
- Восстановление исходных параметров Windows доступно через кнопку возврата в интерфейсе.

### 7. Оконный режим и системный трей

- **Окно без стандартной рамки (`decorations: false`)**: перемещение за область заголовка с изоляцией кликов по кнопкам управления.
- **Кнопки управления**: сворачивание, полноэкранный режим и закрытие в трей.
- **Системный трей Windows**:
  - Иконка в панели задач.
  - Левый клик по иконке скрывает или отображает окно.
  - Контекстное меню по правому клику: «Открыть GhostTweak», «Быстрая оптимизация», «Выход из приложения».
  - При закрытии окна приложение продолжает работать в фоне.

### 8. Защита и лицензирование

- Расчет аппаратного идентификатора (HWID) на базе `MachineGuid` из реестра Windows и хэша SHA-256.
- Шифрование локального файла лицензии (`license.gt`) с привязкой к HWID компьютера.
- Проверка среды исполнения через Win32 API `IsDebuggerPresent`, `CheckRemoteDebuggerPresent` и проверка запущенных процессов отладки.

## Безопасность и античиты

- Все изменения реестра обратимы и подлежат восстановлению через раздел резервных копий.
- Приложение не внедряется в память процессов и не модифицирует игровые файлы.
- Совместимо со всеми распространенными античитами: Valve Anti-Cheat (VAC), Riot Vanguard, Easy Anti-Cheat (EAC) и BattlEye.
