🚀 1. Быстрый старт: Инструменты в 1 клик

В корне репозитория заготовлены скрипты для мгновенного управления проектом без терминала:

setup_env.bat Проверка и автоматическая доустановка Node.js, Rust и всех пакетов.
keygen.bat Интерактивный генератор любых лицензий и ключей для клиентов.
build.bat Полная компиляция релизного EXE с цифровой подписью Authenticode.
run_dev.bat Мгновенный запуск десктоп-приложения в режиме живой разработки.

⚙️ 3. Сборка приложения из исходников

Если вы хотите изменить логотипы, названия, цветовую гамму или добавить новые твики:

  • Фронтенд: папка src/ (React 19, TypeScript, Tailwind CSS).
  • Системное ядро: папка src-tauri/src/commands/ (Rust, Win32 API, чистка реестра, таймеры).
  • Готовый бинарник: после запуска build.bat готовый файл лежит в releases/GhostTweak_Portable.exe (12.5 МБ).

🌐 4. Промо-сайт (Next.js 15) на Vercel

Промо-сайт расположен в папке website/ и готов к бесплатной публикации на Vercel:

  • Импортируйте репозиторий в панель Vercel.
  • Укажите Root Directory: website.
  • Сайт автоматически подхватит скачивание GhostTweak_Portable.exe и кассовые кнопки.
