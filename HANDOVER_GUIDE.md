## 2. Как генерировать лицензионные ключи для покупателей

В проект встроена автономная криптографическая система (HMAC-SHA256). **Вам не нужны базы данных или сервера** — ключи проверяются локально в приложении.

### Способ 1: Через быстрый лаунчер (Рекомендуется)
Дважды кликните на файл в корне:
```bat
keygen.bat
```
1. Выберите тарифный план:
   - `[1]` **VIP Lifetime** (Бессрочная лицензия)
   - `[2]` **Pro Monthly** (Подписка на 30 дней)
   - `[3]` **24h Esports Pass** (Суточный турнирный пропуск на 24 часа)
   - `[4]` **Trial Access** (Пробный доступ на 3 дня)
   - `[5]` **Cyber Arena / Club LAN** (Лицензия для компьютерных клубов)
2. Введите HWID клиента (если клиент хочет привязать ключ к своему ПК) или **просто нажмите Enter** для создания **Универсального мастер-ключа**, который активируется на любом компьютере.
3. Скопируйте ключ и отправьте покупателю в Telegram или на почту.

### Готовые универсальные мастер-ключи (для тестов и демонстраций):
* **VIP Lifetime (Вечный доступ):** `GHOST-VIP-CBDE-65CB-6DDD`
* **Pro Monthly (30 дней):** `GHOST-MTH-4E43-ECEB-620A`
* **24h Esports Pass (24 часа):** `GHOST-DAY-F76A-0DCC-9A06`

## 3. Сборка приложения из исходников

Если вы внесли изменения в код и хотите собрать новый `.exe`:

### Системные требования:
* Windows 10 или 11 (x64)
* **Node.js** 18+ или 20+ ([nodejs.org](https://nodejs.org))
* **Rust** 1.80+ ([rustup.rs](https://rustup.rs)) с тулчейном `stable-x86_64-pc-windows-msvc`
* **Visual Studio Build Tools** (компоненты «Разработка классических приложений на C++»)

### Команда сборки:
Просто запустите в терминале или двойным кликом:
```bat
build.bat
```
Скрипт автоматически:
1. Соберет React 19 фронтенд (`tsc && vite build`).
2. Скомпилирует нативный Rust-бинарник в релизном профиле с максимальной оптимизацией по скорости (`cargo build --release`).
3. Подпишет бинарник сертификатом Authenticode через Windows SDK `signtool.exe`.
4. Скопирует свежий `GhostTweak_Portable.exe` в папки `releases/` и `website/public/downloads/`.

## 4. Развертывание промо-сайта на Vercel

Сайт работает на **Next.js 15 (App Router)** и бесплатно размещается на платформе Vercel.

### Пошаговое подключение:
1. Зарегистрируйтесь или войдите на [vercel.com](https://vercel.com).
2. Нажмите **«Add New...» -> «Project»**.
3. Импортируйте ваш переданный GitHub-репозиторий `GhostTweak`.
4. В поле **Root Directory** нажмите «Edit» и выберите папку: **`website`**.
5. Нажмите **«Deploy»**. 
   *Через 40 секунд сайт будет опубликован в глобальном интернете.*
6. В настройках Vercel (`Settings -> Domains`) вы можете бесплатно привязать любой собственный домен (например, `ghosttweak.ru` или `ghosttweak.com`).

## 5. Где изменить свои контакты и реквизиты оплаты

### 1. На промо-сайте:
* **Модальное окно покупки (касса):**  
  Файл: `website/src/components/CheckoutModal.tsx`  
  В строках 60–90 укажите свой Telegram-ник (например, `@your_telegram`) и email для приема чеков.
* **Футер сайта (подвал):**  
  Файл: `website/src/components/Footer.tsx`  
  Укажите ссылки на ваш Telegram-канал, группу поддержки и репозиторий.

### 2. В десктопном приложении:
* **Окно улучшения тарифа (UpgradeModal):**  
  Файл: `src/components/UpgradeModal.tsx`  
  Ссылка на страницу покупки (по умолчанию открывает ваш сайт с тарифами).
* **Сведения о поддержке:**  
  Файл: `src/pages/Settings.tsx`  
  Email и ссылка на поддержку пользователей.

После изменения контактов:
```bash
git add .
git commit -m "Update owner contacts and payment info"
git push origin main
```
*Vercel автоматически обновит сайт в течение 1 минуты.*

## 6. Модель монетизации и каналы трафика

Проект настроен по схеме **честного Freemium**:
1. **Бесплатный вход (Community Edition):**  
   Базовая калибровка CS2/Valorant, профиль Esports и очистка памяти Standby List бесплатны. Это привлекает игроков и создает сарафанное радио без рекламного бюджета.
2. **Платные тарифы (PRO / VIP):**  
   - **24h Pass (149 ₽):** Импульсивная покупка на турниры и вечера каток.
   - **Pro Monthly (790 ₽):** Подписка на соревновательный рейтинговый сезон (30 дней).
   - **VIP Lifetime (1 490 ₽):** Максимальный средний чек за пожизненный доступ с Match Turbo и аппаратным таймером 0.5 мс.

### Рекомендуемые источники трафика:
* **Shorts / TikTok / Reels:** Короткие видео формата «Как убрать микрофризы в CS2 за 2 клика» с демонстрацией осциллограммы латентности.
* **B2B:** Предложение клубной лицензии (Cyber Arena) локальным компьютерным клубам.
