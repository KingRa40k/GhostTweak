# GhostTweak — Быстрый старт

[ Русский ] | [ English Owner Guide ](docs/01_BUYER_GUIDE_EN.md)

Руководство для быстрого ориентирования в репозитории GhostTweak: запуск скомпилированного приложения, выпуск лицензионных ключей, приём оплат и сборка релизов из исходного кода.

---

## 1. Запуск приложения (без сборки)

Готовые скомпилированные исполняемые файлы находятся в каталоге [`releases/`](./releases):

- **Portable:** [`releases/GhostTweak_Portable.exe`](./releases) — единый файл, запускается сразу без установки.
- **Installer:** [`releases/GhostTweak_Setup_v1.0.0.exe`](./releases) — стандартный установщик Windows (NSIS).
- **MSI:** [`releases/GhostTweak_v1.0.0.msi`](./releases) — пакет для автоматического развертывания.

### Мастер-ключ для активации PRO-режима:
```text
GHOST-VIP-PRO-2026
```
Используйте этот ключ в окне активации PRO для проверки полного функционала программы.

## 3. Важно: Локальная разработка («локалка») vs Продакшен и деплой в Git

### В чём разница между «локалкой» и «продакшеном»?

| Параметр | Локальная разработка («локалка») | Продакшен («прод») |
| :--- | :--- | :--- |
| **Где работает** | На вашем личном компьютере (`localhost:3000`, `127.0.0.1`). | На публичном хостинге (Vercel) с вашим доменом (`https://yourdomain.com`). |
| **Кто видит** | Только вы в своём локальном браузере. | Все клиенты, игроки и покупатели в интернете. |
| **Файлы для загрузки** | Локальные файлы в папках `releases/` и `website/public/downloads/`. | Исполняемые файлы, доступные для скачивания пользователями через CDN. |
| **Контакты и оплата** | Изменения в `paymentConfig.ts` или ценах работают только на вашем ПК. | Вступают в силу для покупателей только после сборки на сервере. |

### Главное правило владельца: деплой в Git после каждого изменения

> **Запомните:** Если вы отредактировали файлы на своём компьютере (например, указали email администратора, подключили платёжный шлюз в [`website/src/lib/paymentConfig.ts`](./website/src/lib/paymentConfig.ts), обновили цены или скомпилировали новые версии `.exe`), эти изменения **не появятся на сайте у реальных покупателей автоматически**, пока вы не зафиксируете их и не отправите в Git-репозиторий!

#### Порядок обновления проекта:
1. **При изменении сайта, контактов или реквизитов оплаты:**
   ```bash
   # 1. Проверить измененные файлы
   git status

   # 2. Добавить все изменения
   git add .

   # 3. Зафиксировать изменения с понятным описанием
   git commit -m "Update payment config and contacts"

   # 4. Отправить в репозиторий (запускает автоматический деплой Vercel)
   git push origin main
   ```
   *Через 30–60 секунд Vercel автоматически соберет проект, и изменения сразу станут доступны на вашем домене.*

2. **При изменении кода десктопного приложения (`src/` или `src-tauri/`):**
   * Сначала скомпилируйте приложение локально, запустив `build.bat`.
   * Скрипт пересоберет `.exe` и скопирует их в `releases/` и `website/public/downloads/`.
   * Затем отправьте обновленные бинарники в Git:
     ```bash
     git add .
     git commit -m "Release new desktop version"
     git push origin main
     ```
   * После автодеплоя Vercel посетители сайта будут скачивать уже новую версию программы.

## 4. Основные сценарии работы

### А. Генерация лицензионных ключей для клиентов (в 1 клик)
Для быстрого создания ключей запустите готовый скрипт в корне репозитория:
```bat
generate_keys.bat
```
Скрипт откроет интерактивное меню Windows, где можно в один клик:
1. Выпустить бессрочный ключ (**VIP Lifetime**).
2. Выпустить ключ на **30 дней** или **24 часа**.
3. Сгенерировать пачку из **50 ключей** в файл `keys.txt` для загрузки в ваш платёжный сервис.
4. Запустить локальный REST API сервер лицензий.

Либо используйте Python напрямую в каталоге `tools/`:
```bash
# Пожизненный PRO-ключ
python tools/license_generator.py --type lifetime

# Месячный ключ на 30 дней
python tools/license_generator.py --type monthly

# Пакетная генерация 50 ключей в файл
python tools/license_generator.py --type lifetime --count 50 --output keys.txt
```
Подробнее: [`docs/03_LICENSING_AND_MONETIZATION.md`](./docs/03_LICENSING_AND_MONETIZATION.md).

### Б. Автоматизация выдачи лицензий и онлайн-оплата
В проекте предусмотрен безопасный режим (Safe Mode) и поддержка всех популярных платёжных систем:
1. **Безопасный режим по умолчанию:** если платёжная система ещё не подключена, окно покупки на сайте автоматически информирует клиента и предлагает отправить заявку на почту администратора с предзаполненным тарифом.
2. **Подключение оплат:** в файле [`website/src/lib/paymentConfig.ts`](./website/src/lib/paymentConfig.ts) подготовлены готовые пресеты для **Stripe Payment Links, Lava.top, Boosty, ЮKassa, Robokassa и Cryptomus**. Для включения достаточно указать вашу платёжную ссылку и выставить `NEXT_PUBLIC_PAYMENT_ENABLED=true` в `website/.env`.
3. **Автовыдача:** вы можете загрузить список ключей из `keys.txt` в автовыдачу цифровых товаров платёжного шлюза, либо поднять сервер верификации `python tools/license_server.py --port 8080` для автоматической активации через API.
Подробнее: [`tools/README.md`](./tools/README.md).

### В. Система проверки обновлений
В GhostTweak встроена автоматическая проверка новых версий:
- В приложении: раздел **«Настройки»** -> карточка **«Обновления GhostTweak»** с кнопкой мгновенной проверки.
- В бэкенде: нативный Rust-метод `check_for_updates`, сверяющий версию с `https://ghosttweak.com/api/version.json` (с тайм-аутом и бесшумным fallback при отсутствии сети).
- Для публикации новой версии достаточно изменить номер версии и описание в [`website/public/api/version.json`](./website/public/api/version.json) и [`releases/latest.json`](./releases/latest.json).

### Г. Тестовая цифровая подпись Authenticode
Чтобы протестировать автоматическую подпись бинарников в `build.bat` ещё до покупки дорогого EV-сертификата:
```bat
scripts\create_test_certificate.bat
```
Скрипт создаст локальный сертификат `scripts\test_cert.pfx` и настроит переменные в `.env`. После этого `build.bat` будет автоматически подписывать исполняемый файл через Microsoft `signtool.exe`.


### Д. Развертывание маркетингового сайта
Промо-сайт разработан на Next.js и находится в каталоге `website/`.
- Инструкция по бесплатному деплою на Vercel с привязкой собственного домена: [`docs/05_DEPLOYMENT_VERCEL.md`](./docs/05_DEPLOYMENT_VERCEL.md).
- Локальный запуск сайта:
  ```bash
  cd website
  npm install
  npm run dev
  ```

### Е. Ребрендинг и замена контактных данных
Для изменения названия бренда, контактов службы поддержки, цен или цветовой темы следуйте чек-листу в [`docs/04_CUSTOMIZATION_AND_CONTACTS.md`](./docs/04_CUSTOMIZATION_AND_CONTACTS.md).

### Ж. Сборка приложения из исходного кода
После внесения изменений в код:
1. Запустите `build.bat` в корне проекта.
2. Скрипт скомпилирует фронтенд и бэкенд, а затем скопирует готовые исполняемые файлы в каталоги `releases/` и `website/public/downloads/`.
Подробнее о сертификатах и цифровой подписи Authenticode: [`docs/02_BUILD_AND_RELEASE.md`](./docs/02_BUILD_AND_RELEASE.md).
