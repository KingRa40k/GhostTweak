# Регламент бета-тестирования GhostTweak (v1.0.0-beta.1)

Инструкция для участников тестирования GhostTweak v1.0.0-beta.1: сценарии проверки функционала, снятие диагностических данных и отправка отчетов.

---

## 1. Запуск и активация тестовой версии

1. **Запуск от имени Администратора:**
   - Для управления низкоуровневыми системными параметрами и очистки системных каталогов запускайте приложение с повышенными привилегиями (`ПКМ -> Запуск от имени администратора`).
   - При обычном запуске кликните по индикатору статуса прав в верхней панели для перезапуска через UAC.

2. **Ключи активации бета-теста:**
   В окне ввода ключа используйте:
   ```text
   GHOST-BETA-2026
   ```
   *Дополнительные тестовые ключи:* `BETATESTER2026`, `GHOST-BETA-ACCESS`, `GHOST-BETA-PRO`.

3. **Статус активации:**
   - Включается план «BETA TESTER PASS» с доступом ко всем модулям.
   - Идентификатор оборудования (HWID) привязывается к активной сессии.

## 2. Сценарии тестирования

### Сценарий А: Режим ускорения перед игрой (Match Turbo)
- **Расположение:** Главная панель или раздел «Игры».
- **Действия программы:**
  1. Сброс Standby List оперативной памяти через NT API.
  2. Активация таймера ядра 0.5 мс (`NtSetTimerResolution`).
  3. Определение игровых процессов (`cs2.exe`, `valorant.exe`, `dota2.exe`, `r5apex.exe`) с назначением высокого приоритета CPU и ввода-вывода.
- **Критерий проверки:** Плавность времени кадра (frametime), отсутствие статтеров при первом спавне на карте и стабильность 0.1% Low FPS.

### Сценарий Б: Очистка кэшей (Cleaner)
- **Расположение:** Раздел «Очистка».
- **Критерий проверки:**
  - Сканирование кэша шейдеров DirectX, NVIDIA GLCache / D3DSCache, AMD Radeon Cache.
  - Очистка каталога `%TEMP%` и кэша Windows Update.
  - Корректность последующей компиляции шейдеров при запуске игр.

### Сценарий В: Твики реестра и служб (Tweaks)
- **Расположение:** Раздел «Твики».
- **Ключевые параметры:**
  - `ultimate_perf_power` — Схема электропитания «Максимальная производительность».
  - `hags_gpu_scheduling` — Аппаратное планирование GPU (HAGS).
  - `gpu_msi_mode` — Режим прерываний MSI для видеокарты.
  - `disable_sysmain` — Отключение службы SysMain (Superfetch).
  - `optimize_network` — Отключение задержек Nagle (TcpAckFrequency, TCPNoDelay).
- **Безопасность:** Перед каждым изменением создаётся файл резервной копии в `%APPDATA%\GhostTweak\backups\`.

### Сценарий Г: Монитор и игровой DNS (Settings)
- **Расположение:** Раздел «Настройки».
- **Критерий проверки:**
  - Кнопка «Синхронизировать» для считывания физической частоты развертки монитора.
  - Переключение DNS-серверов (Cloudflare 1.1.1.1, Google 8.8.8.8, Quad9 9.9.9.9) и проверка сетевого пинга.

## 3. Снятие диагностического отчета

При возникновении ошибок или некорректном поведении:
1. Перейдите в раздел **«Настройки»**.
2. В блоке программы бета-тестирования нажмите **«Скопировать диагностический отчет ПК»**.
3. Отчет в формате Markdown копируется в буфер обмена (включает характеристики ОС, CPU, GPU, RAM, HWID и статус примененных твиков).
4. Передайте отчет разработчикам с описанием воспроизведения ошибки.

---

## 4. Сброс лицензии и перепривязка

Для проверки поведения первого запуска или авторизации:
- Нажмите «Ключ» в блоке профиля -> «Сменить ключ / Выйти».
- Либо удалите локальный файл ключа: `%APPDATA%\GhostTweak\license.gtkey`.
