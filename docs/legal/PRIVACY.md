# Политика конфиденциальности (Privacy Policy) GhostTweak

**Дата вступления в силу:** 8 сентября 2026 г.  
**Версия документа:** 1.0.0

Настоящая Политика конфиденциальности определяет порядок обработки и защиты информации пользователей при использовании настольного программного обеспечения **GhostTweak** (далее — «Приложение») и связанных с ним веб-ресурсов (далее — «Сайт»).

---

## 1. Базовый принцип: локальная обработка данных (Zero Telemetry)

Приложение разработано на основе принципа **Local-First / Zero Telemetry**:
1. Приложение **не собирает, не сохраняет и не передает** персональные данные пользователей на удаленные серверы.
2. Приложение функционирует полностью автономно на локальном компьютере пользователя.
3. В код Приложения не интегрированы сторонние аналитические трекеры, рекламные SDK, пиксели отслеживания или системы сбора поведенческой телеметрии.

---

## 2. Категории данных и цели их локального использования

Приложение запрашивает и обрабатывает исключительно техническую информацию, необходимую для выполнения функций оптимизации операционной системы:

### 2.1. Аппаратный идентификатор (HWID)
* **Состав данных:** криптографический хэш (SHA-256), формируемый на базе значения реестра Windows `HKLM\SOFTWARE\Microsoft\Cryptography\MachineGuid` или серийного номера материнской платы.
* **Цель обработки:** локальная криптографическая проверка подлинности лицензионного ключа и защита сохраненного файла лицензии (`license.gt`).
* **Хранение:** хэш сохраняется исключительно в локальном зашифрованном хранилище конфигурации `%APPDATA%\GhostTweak\` и не передается во внешние сети.

### 2.2. Спецификации оборудования и операционной системы
* **Состав данных:** модель центрального процессора (CPU), видеокарты (GPU), объем оперативной памяти (RAM), версия и сборка Windows, разрешение и частота обновления монитора.
* **Цель обработки:** отображение диагностической панели в интерфейсе пользователя и расчет рекомендованных параметров оптимизации (количество потоков для параметров запуска игр, объем кэша).
* **Хранение:** данные опрашиваются через стандартные вызовы Win32 API (`GetSystemInfo`, `EnumDisplaySettingsW`, `GlobalMemoryStatusEx`) в режиме реального времени и не сохраняются в постоянных журналах.

### 2.3. Временные файлы и кэши
* **Состав данных:** файлы временных каталогов (`%TEMP%`, `C:\Windows\Temp`), кэши шейдеров DirectX, NVIDIA (`GLCache`, `NV_Cache`) и AMD (`DxcCache`), кэш обновлений Windows Update.
* **Цель обработки:** сканирование дискового пространства и удаление устаревших файлов по прямой команде пользователя.
* **Принцип безопасности:** сканирование и удаление производятся строго в пределах предопределенных системных каталогов. Приложение не анализирует содержимое личных документов, переписок или мультимедийных файлов.

### 2.4. Резервные копии реестра (Backups)
* **Состав данных:** экспортированные ветки системного реестра Windows, затрагиваемые при включении твиков производительности.
* **Цель обработки:** обеспечение возможности отката изменений к исходному состоянию системы.
* **Хранение:** резервные копии сохраняются в виде стандартных файлов реестра (`.reg`) в локальном каталоге пользователя `%APPDATA%\GhostTweak\backups\`.

## 3. Сетевая активность

1. **Десктопное приложение:**
   - Не выполняет автоматических фоновых сетевых запросов.
   - Не производит скрытых исходящих подключений.
   - Функция проверки DNS выполняет локальную смену шлюзов в сетевом адаптере через утилиту Windows `netsh` исключительно при ручном выборе шлюза пользователем (Cloudflare, Google, Quad9, DHCP).
2. **Официальный сайт:**
   - Веб-сайт проекта использует базовые технические заголовки веб-сервера для обеспечения защищенного соединения (HTTPS/TLS).
   - На сайте не используются трекеры сторонних рекламных сетей.

---

## 4. Защита и безопасность данных

1. Все локальные файлы настроек и лицензий защищены механизмом аппаратного маскирования, предотвращающим их перенос на сторонние устройства.
2. Приложение требует запуска с правами администратора Windows (UAC Elevation) исключительно для выполнения системных вызовов: управления службами Windows, изменения параметров энергопотребления и очистки общесистемных каталогов.
3. Приложение не выполняет внедрение кода (code injection) в адресное пространство сторонних процессов и не перехватывает пользовательский ввод (клавиатурные шпионы, кейлоггеры).

---

## 5. Права пользователя

В соответствии с применимыми стандартами защиты данных (включая принципы GDPR и 152-ФЗ):
* **Право на доступ и переносимость:** пользователь имеет полный доступ ко всем файлам, создаваемым Приложением (каталог `%APPDATA%\GhostTweak\`).
* **Право на удаление:** полное удаление Приложения через стандартную панель удаления программ Windows или деинсталлятор удаляет все установленные бинарные файлы. Пользователь может в любой момент вручную удалить директорию `%APPDATA%\GhostTweak\`, что приведет к полному уничтожению локальных настроек и резервных копий.
* **Право на откат:** пользователь может в любой момент восстановить оригинальные параметры системы через встроенный модуль резервных копий либо вручную запустив созданные `.reg` файлы.
