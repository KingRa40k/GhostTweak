# 🏛️ Архитектура и структура проекта GhostTweak

Данный раздел подробно описывает устройство кодовой базы, стек технологий и назначение каждого каталога в проекте.

---

## 1. Стек технологий

| Модуль | Технологии | Назначение |
| :--- | :--- | :--- |
| **Ядро приложения** | Rust 2021, Tauri v2.2 | Прямой вызов Win32 API, таймер ядра (0.5 мс), замеры задержек, очистка кэшей, твики реестра |
| **Интерфейс приложения** | React 19, TypeScript, Tailwind CSS, Lucide Icons | Высокопроизводительный темный интерфейс (60+ FPS), динамические темы, мультиязычность |
| **Маркетинговый сайт** | Next.js 15 (App Router), React 19, Tailwind, Framer Motion | Презентация продукта, интерактивный макет, таблица сравнения, загрузка дистрибутивов |

## 2. Структура каталогов

```
valiant-maxwell/
├── build.bat                   # 🚀 Универсальный скрипт сборки релиза в один клик
├── package.json                # Зависимости фронтенда десктопного приложения
├── src-tauri/                  # 🦀 Бэкенд на Rust (Tauri v2)
│   ├── Cargo.toml              # Зависимости Rust (tauri, winreg, dirs, serde, walkdir)
│   ├── tauri.conf.json         # Конфигурация окна, бандла, прав доступа и CSP
│   ├── build.rs                # Скрипт линковки и компиляции манифеста Windows
│   └── src/
│       ├── main.rs             # Точка входа в процесс Windows
│       ├── lib.rs              # Инициализация плагинов, системного трея и регистрация команд
│       └── commands/           # Модули команд WinAPI:
│           ├── system_info.rs      # Сбор данных процессора, ОЗУ, видеокарты, EDID частот монитора
│           ├── performance.rs      # Мультимедийный таймер ядра (0.5 мс), сброс RAM, DNS пресеты
│           ├── cleaner.rs          # Сканирование и очистка DirectX, NVIDIA, AMD и Temp кэшей
│           ├── tweaks.rs           # Твики реестра Win32, игровые параметры CS2, DiagTrack
│           ├── backup.rs           # Автоматический экспорт и импорт веток реестра (.reg)
│           ├── security.rs         # Антиотладка, HWID привязка, криптографическая проверка ключей
│           └── window_controls.rs  # Управление кастомным заголовком окна и сворачивание в трей
├── src/                        # ⚛️ Фронтенд десктопного приложения (React 19)
│   ├── App.tsx                 # Корневой лейаут приложения, инициализация безопасности и темы
│   ├── main.tsx                # Точка монтирования React DOM
│   ├── pages/                  # Экраны приложения:
│   │   ├── Dashboard.tsx       # Главная панель мониторинга, сводка ресурсов и кнопка "Optimize All"
│   │   ├── Cleaner.tsx         # Сканер мусора с выбором категорий для безопасной очистки
│   │   ├── Tweaks.tsx          # Твики реестра с тумблерами и разбивкой по категориям
│   │   ├── GameOptimizer.tsx   # Профиль CS2, замеры частоты кадров, таймер ядра и DNS
│   │   ├── Profiles.tsx        # Сценарные профили (Esports, AAA, Streamer, Battery)
│   │   ├── Backups.tsx         # Менеджер точек отката реестра (.reg) с восстановлением в 1 клик
│   │   ├── Settings.tsx        # Настройки, выбор языка, кастомизация палитры и ссылки саппорта
│   │   └── AuthScreen.tsx      # Футуристичный экран активации с аппаратной привязкой к HWID
│   ├── components/             # Переиспользуемые компоненты (TitleBar, Sidebar, Modal и др.)
│   ├── lib/                    # Утилиты:
│   │   ├── tauri.ts            # Типизированный мост вызова нативных команд Tauri
│   │   ├── license.ts          # Локальное хранение и проверка статуса авторизации
│   │   ├── i18n.tsx            # Двуязычная система локализации (RU / EN)
│   │   └── theme.ts            # Цветовые темы (Cyberpunk Neon, Ghost Purple, Matrix Green и др.)
│   └── styles/                 # Глобальные стили Tailwind и неоновые анимации
└── website/                    # 🌐 Лендинг и промо-сайт (Next.js 15)
    ├── package.json            # Зависимости лендинга
    ├── src/
    │   ├── app/                # Next.js App Router (layout.tsx, page.tsx)
    │   ├── components/         # Секции сайта (Hero, AppMockup, CoreArsenal, Pricing, FAQ)
    │   └── lib/                # Локализация лендинга (i18n.tsx) и темы оформления
    └── public/
        └── downloads/          # Скомпилированные инсталляторы (.exe, .msi, Portable)
```

## 3. Взаимодействие фронтенда и ядра

1. Пользователь совершает действие в интерфейсе React (например, нажимает кнопку «Активировать таймер 0.5 мс» или «Очистить кэш»).
2. Фронтенд вызывает функцию `invoke('command_name', { args })` через хелпер [`src/lib/tauri.ts`](../src/lib/tauri.ts).
3. Tauri безопасно транслирует вызов в соответствующий обработчик в папке `src-tauri/src/commands/`.
4. Rust-ядро выполняет нативный вызов Win32 API с правами администратора и возвращает типизированный результат или структурированную ошибку.
5. Интерфейс React обновляет состояние без перезагрузки и отображает плавную анимацию.
