# 📦 Сборка дистрибутивов и релизы (.exe, .msi, Portable)

В этом руководстве описан процесс компиляции десктопного приложения под Windows в различных форматах (инсталлятор, MSI и переносимая версия).

---

## 1. Системные требования для сборки

Для успешной компиляции нативного кода на компьютере разработчика должны быть установлены:
1. **Node.js**: v18.0.0 или новее.
2. **Rust**: Установленный через официальный установщик [rustup.rs](https://rustup.rs/) (канал `stable-x86_64-pc-windows-msvc`).
3. **Visual Studio C++ Build Tools**: В установщике Visual Studio Installer должна быть отмечена галочка **«Разработка классических приложений на C++»** (Desktop development with C++).

---

## 2. Сборка в один клик через `build.bat`

В корне проекта находится готовый портативный скрипт [`build.bat`](../build.bat).
* Просто запустите его двойным кликом из проводника Windows или через командную строку:
```cmd
build.bat
```
Скрипт автоматически перейдет в директорию ядра и запустит компиляцию в режиме максимальной оптимизации (`cargo build --release`).

---

## 3. Сборка всех пакетов установщиков (NSIS, MSI, Portable)

Чтобы сгенерировать полноценные дистрибутивы с установщиком и ярлыками на рабочем столе, выполните в корне проекта:

```bash
# 1. Убедитесь, что зависимости фронтенда установлены
npm install

# 2. Запустите сборку пакета Tauri
npm run tauri build
```

Процесс займет от 1 до 3 минут. По завершении в папке `src-tauri/target/release/` появятся:

| Тип дистрибутива | Расположение файла | Описание |
| :--- | :--- | :--- |
| **NSIS Setup (.exe)** | `src-tauri/target/release/bundle/nsis/GhostTweak_1.0.0_x64-setup.exe` | Полноценный современный мастер установки с выбором папки и созданием ярлыков. |
| **Windows Installer (.msi)** | `src-tauri/target/release/bundle/msi/GhostTweak_1.0.0_x64_en-US.msi` | Корпоративный установщик Windows для системных администраторов. |
| **Portable (.exe)** | `src-tauri/target/release/ghosttweak.exe` | Портативный исполняемый файл без установки. Запускается напрямую даже с флешки. |

---

## 4. Смена номера версии приложения

Если вы выпускаете обновление (например, v1.1.0):
1. В корневом [`package.json`](../package.json): обновите строку `"version": "1.1.0"`.
2. В конфигурации Tauri [`src-tauri/tauri.conf.json`](../src-tauri/tauri.conf.json): обновите `"version": "1.1.0"`.
3. В файле манифеста Rust [`src-tauri/Cargo.toml`](../src-tauri/Cargo.toml): обновите `version = "1.1.0"`.
4. В файле сайта [`website/package.json`](../website/package.json): обновите `"version": "1.1.0"`.

---

## 5. Замена иконок приложения

Все иконки программы хранятся в каталоге `src-tauri/icons/`:
* `icon.ico` — иконка для Windows (используется для файла `.exe` и ярлыков).
* `icon.png` / `128x128.png` / `32x32.png` — растровые иконки для системного трея и окна.

Чтобы быстро сгенерировать весь набор иконок из одного исходного PNG-изображения (1024x1024):
```bash
npm run tauri icon path/to/your/new_icon.png
```
