# Развертывание маркетингового сайта на Vercel

Маркетинговый сайт проекта создан на базе Next.js 15 (App Router) и оптимизирован для размещения на платформе Vercel с автоматическим SSL-сертификатом и CDN.

---

## Пошаговая инструкция по деплою

### Шаг 1. Авторизация на Vercel
1. Перейдите на [vercel.com](https://vercel.com).
2. Выполните вход через GitHub-аккаунт.

### Шаг 2. Импорт репозитория
1. В панели управления Vercel нажмите **Add New...** -> **Project**.
2. В списке репозиториев найдите `valiant-maxwell` (или имя вашего форка/репозитория) и нажмите **Import**.

### Шаг 3. Настройка каталога сборки (Root Directory)
Репозиторий объединяет десктопное приложение и промо-сайт, поэтому для сайта нужно указать подпапку:
1. В строке **Root Directory** нажмите кнопку **Edit**.
2. Укажите каталог `website`.
3. В разделе **Framework Preset** должен быть выбран `Next.js`. Менять остальные параметры сборки не требуется.

### Шаг 4. Запуск деплоя
* Нажмите кнопку **Deploy**.
* По завершении компиляции Vercel предоставит рабочий URL вида:
  `https://ghosttweak-xxx.vercel.app`

---

## Привязка собственного домена

1. В настройках проекта Vercel перейдите в раздел **Settings** -> **Domains**.
2. Введите имя домена и нажмите **Add**.
3. Добавьте указанные Vercel записи в панели управления DNS вашего регистратора доменов (A-запись `76.76.21.21` или CNAME).
4. После обновления DNS сайт станет доступен по вашему домену с автоматическим HTTPS.

## Важно: Локальная разработка vs Продакшен

Перед началом работы важно понимать разницу между средами:

1. **Локалка (ваш ПК):**
   * Вы редактируете файлы исходного кода, меняете email администратора в `website/src/lib/paymentConfig.ts`, настраиваете цены или тестируете интерфейс через `npm run dev`.
   * **Все эти изменения видите только вы.** Они находятся на вашем локальном диске и не влияют на реальный сайт в интернете.
2. **Продакшен (Vercel):**
   * Это живой сайт в интернете, на который заходят покупатели.
   * Он обновляется **только тогда**, когда вы отправляете зафиксированные изменения в репозиторий через Git.

## Автоматический деплой через Git (CI/CD)

После внесения любого важного изменения в проект выполните отправку в репозиторий:

```bash
# 1. Проверить статус измененных файлов
git status

# 2. Добавить измененные файлы в индекс
git add .

# 3. Создать коммит с кратким комментарием
git commit -m "Update contacts and payment gateway configuration"

# 4. Отправить изменения в основную ветку GitHub
git push origin main
```

### Что происходит после `git push`:
1. Vercel мгновенно получает уведомление (Webhook) от GitHub о новом коммите.
2. Запускается процесс изолированной сборки (`next build`).
3. Через 30–60 секунд новая версия сайта автоматически публикуется на вашем домене без простоя (Zero Downtime).

> **Частая ошибка:** Внести изменения в файлы на компьютере, не сделать `git push` и удивляться, почему на сайте ничего не изменилось. Помните: любое важное изменение обязательно должно быть закоммичено и отправлено в Git!
