# ❓ Часто задаваемые вопросы и решение проблем (FAQ & Troubleshooting)

Здесь собраны ответы на самые популярные технические вопросы, с которыми может столкнуться новый владелец или конечный пользователь GhostTweak.

---

## 1. Зачем приложению нужны права администратора?

**Ответ:**
GhostTweak взаимодействует с ядром Windows на низком уровне:
* Настройка мультимедийного таймера высокой точности (0.500 мс) через системные вызовы `timeBeginPeriod`.
* Твики раздела реестра `HKEY_LOCAL_MACHINE` (отключение фоновой телеметрии DiagTrack, отключение алгоритма Nagle в сетевом стеке TCP/IP).
* Очистка системного кэша `C:\Windows\SoftwareDistribution\Download` и `C:\Windows\Temp`.

Для выполнения этих операций Windows в обязательном порядке запрашивает подтверждение UAC (Контроль учетных записей). Это стандартное поведение для любого профессионального софта оптимизации.

---

## 2. Безопасность: почему SmartScreen может предупреждать при первом запуске?

**Ответ:**
Любая свежескомпилированная программа без платного цифрового сертификата EV Code Signing (который стоит от \$300/год) временно помечается фильтром Windows SmartScreen плашкой *«Неизвестный издатель»*.
* Это **не вирус**, а стандартная реакция Windows на новые файлы. Чтобы запустить программу, пользователю достаточно нажать: *«Подробнее»* -> *«Выполнить в любом случае»*.
* По мере того как программу скачивают и запускают разные пользователи, SmartScreen автоматически накапливает репутацию и перестает показывать предупреждение.
* При желании новый владелец может подписать файл своим сертификатом через утилиту `signtool.exe`.

## 3. Ошибка сборки: «link.exe not found» или ошибки MSVC

**Причина:**
В системе установлен компилятор Rust, но отсутствуют нативные C++ библиотеки Windows SDK.

**Решение:**
1. Скачайте и запустите **Visual Studio Installer** (бесплатная версия Community или Build Tools).
2. Нажмите **«Изменить»** и включите рабочий набор **«Разработка классических приложений на C++»**.
3. Убедитесь, что в компонентах справа отмечены:
   * *MSVC v143 — средства сборки C++*.
   * *Пакет Windows 10/11 SDK*.
4. Перезапустите терминал и запустите `build.bat` снова.

## 4. Как гарантировать безопасность системы при применении твиков?

**Ответ:**
В модуль [`src-tauri/src/commands/backup.rs`](../src-tauri/src/commands/backup.rs) заложена автоматическая система создания резервных копий:
* Перед изменением любого ключа реестра GhostTweak выполняет нативный экспорт оригинальной ветки в файл `.reg` с отметкой времени в папку `%APPDATA%\GhostTweak\backups\`.
* На вкладке **«Резервные копии» (Backups)** пользователь всегда видит список всех изменений и может в один клик откатить любой параметр назад без перезагрузки или переустановки Windows.

---

## 5. Как сменить порт сервера разработки (Vite 1420 или Next.js 3000)?

* Для десктопного приложения: в файле [`src-tauri/tauri.conf.json`](../src-tauri/tauri.conf.json) параметр `"devUrl": "http://localhost:1420"` и в [`vite.config.ts`](../vite.config.ts) параметр `server.port`.
* Для сайта: запуск командой `npm run dev -- -p 3001`.
