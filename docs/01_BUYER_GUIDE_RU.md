# Руководство покупателя и владельца проекта GhostTweak

Документ содержит инструкции по запуску, проверке, повторной сборке и управлению проектом GhostTweak.

---

## 1. Запуск скомпилированного приложения

В каталоге `releases/` находятся готовые бинарные файлы для Windows 10/11:

* `GhostTweak_Portable.exe` — портативная версия. Запускается сразу без установки.
* `GhostTweak_Setup_v1.0.0.exe` — стандартный NSIS-установщик.
* `GhostTweak_v1.0.0.msi` — установочный пакет MSI для корпоративного развертывания.

Приложению не требуются дополнительные среды выполнения; WebView2 предустановлен в Windows 10 и 11. Для применения системных настроек и твиков запускайте файл от имени администратора.

### Мастер-ключ для активации PRO-режима:
```text
GHOST-VIP-PRO-2026
```
Ключ открывает полный доступ ко всем функциям, неограниченным точкам восстановления реестра и игровым профилям.

## 2. Разработка и сборка из исходного кода

Требования к среде: Node.js 18+, Rust (stable-x86_64-pc-windows-msvc), Visual Studio Build Tools (C++ Desktop).

```bash
# Запуск интерфейса в режиме разработки:
npm install
npm run tauri dev

# Сборка релизных бинарных файлов:
build.bat
```

Скрипт `build.bat` компилирует фронтенд на React 19, собирает Rust-ядро через Tauri CLI и синхронизирует готовые файлы в каталоги `releases/` и `website/public/downloads/`.

## 3. Важно: Локальная среда («локалка») vs Продакшен («прод»)

### Ключевые различия

* **Локальная среда (ваш компьютер):**
  * Сайт работает по адресу `http://localhost:3000` (`npm run dev` в папке `website/`).
  * Приложение открывается через `npm run tauri dev`.
  * Все изменения в файлах (настройки оплат в `paymentConfig.ts`, тексты, контакты, новые бинарники) видны **только вам**.
* **Продакшен (живой интернет):**
  * Маркетинговый сайт опубликован на Vercel под вашим доменом.
  * Реальные пользователи заходят на сайт и скачивают инсталляторы.
  * Запросы покупателей и транзакции происходят на сервере.

### Правило каждого изменения (Деплой в Git):
Чтобы любое изменение на вашем компьютере (новые контакты, подключение платёжки, смена цен, новые версии `.exe`) появилось у реальных пользователей на сайте:
```bash
# 1. Зафиксировать изменения в локальном репозитории
git add .
git commit -m "Update payment config and site settings"

# 2. Отправить в Git (Vercel автоматически обновит сайт в течение 1 минуты)
git push origin main
```
> **Внимание:** Без выполнения `git push` сайт в интернете останется старым, даже если на локальном компьютере в коде всё уже изменено.

## 4. Новые утилиты и инструменты владельца

### 1. Интерактивная генерация ключей в 1 клик
В корне проекта и в каталоге `tools/` размещен скрипт:
```bat
generate_keys.bat
```
Запустите его двойным кликом в Windows для доступа к удобному меню:
- `[1]` Выпуск бессрочного VIP Lifetime ключа
- `[2]` Выпуск месячного ключа на 30 дней
- `[3]` Выпуск суточного ключа на 24 часа
- `[4]` Пакетная генерация 50 ключей в файл `keys.txt` (для импорта в платёжный шлюз)
- `[5]` Запуск REST API сервера лицензий
- `[6]` Просмотр базы данных активных ключей

### 2. Тестовый сертификат цифровой подписи Authenticode
Чтобы проверить автоматическую подпись в `build.bat` без покупки коммерческого сертификата:
```bat
scripts\create_test_certificate.bat
```
Скрипт автоматически создаст `scripts\test_cert.pfx` и пропишет настройки в `.env`. После этого при запуске `build.bat` исполняемый файл будет автоматически подписываться через `signtool.exe`.

### 3. Автоматическая проверка обновлений
- В десктопном приложении на вкладке **«Настройки»** добавлена карточка **«Обновления GhostTweak»** с кнопкой ручной проверки.
- Проверка работает через нативную команду Rust, опрашивающую `https://ghosttweak.com/api/version.json` с быстрым таймаутом и бесшумным fallback.
- Для релиза новой версии обновите версию в `website/public/api/version.json` и `releases/latest.json`.

### 4. Приём платежей: Безопасный режим (Safe Mode) и пресеты
- В файле `website/src/lib/paymentConfig.ts` по умолчанию включен **Safe Mode** (`isLivePaymentEnabled: false`). Если платёжка ещё не подключена, окно покупки сообщает пользователю о регламентных работах и сразу открывает прямую форму заявки на email администратора.
- В коде подготовлены готовые конфигурационные пресеты для **Stripe, Lava, Boosty, ЮKassa, Robokassa и Cryptomus**. Для включения достаточно указать ссылку и выставить `NEXT_PUBLIC_PAYMENT_ENABLED=true` в `website/.env`.

## 6. Состав репозитория

1. `src-tauri/` — исходный код ядра на Rust: вызовы Win32 API, таймер ядра 0.5 мс, управление приоритетами процессов CS2, очистка кэшей шейдеров DirectX, NVIDIA, AMD, управление системными службами.
2. `src/` — исходный код интерфейса: React 19, TypeScript, Tailwind CSS, переключение тем, многоязычность (RU/EN).
3. `website/` — промо-сайт на Next.js 15 (App Router), интерактивная демонстрация интерфейса, таблица сравнения характеристик.
4. `releases/` — скомпилированные исполняемые файлы (`.exe`, установщик, `.msi`).
5. `tools/` — CLI-генератор криптографических лицензий (`license_generator.py`), пакетное меню (`generate_keys.bat`) и REST API сервер лицензий (`license_server.py`).
6. `docs/` — техническая документация и юридические соглашения (`docs/legal/`).
