# Система лицензирования и монетизация GhostTweak

В GhostTweak реализована система криптографической валидации лицензий на базе алгоритма Ed25519, локальная база данных SQLite и REST API сервер для автоматической выдачи ключей.

---

## 1. Архитектура криптографической защиты

1. **Аппаратный идентификатор (HWID):**
   Приложение считывает аппаратные параметры компьютера:
   * Серийный номер физического накопителя через вызов `IOCTL_STORAGE_QUERY_PROPERTY` к `\\.\PhysicalDrive0`.
   * Серийный номер материнской платы из SMBIOS (`BaseBoardSerialNumber`).
   * Регистры процессора через интринсики `core::arch::x86_64::__cpuid(1)`.
   * Хэш SHA-256 формирует детерминированный HWID формата: `GT-A8F3-9B2C-1E4D`.

2. **Асимметричная криптография Ed25519:**
   * В ядро десктопного приложения встроен открытый ключ (`GHOST_ROOT_PUBLIC_KEY`).
   * Закрытый приватный ключ хранится у владельца проекта (в `tools/license_server.py` и `tools/license_generator.py`).
   * Токен лицензии представляет собой структуру `{payload_hex}:{signature_hex}`.
   * Клиент валидирует подпись локально без обязательного подключения к сети.

## 2. Генерация ключей и база данных (SQLite)

Модули лицензирования находятся в каталоге [`tools/`](../tools/).

### А. Генерация ключей через консоль (CLI)
```bash
# 1. Бессрочная VIP-лицензия с привязкой к конкретному HWID:
python tools/license_server.py --create --sub "Client_01" --hwid "GT-ABCD-1234-EF01" --plan VIP_LIFETIME

# 2. Универсальный ключ (активируется на любом ПК):
python tools/license_server.py --create --sub "Reviewer" --hwid "*" --plan VIP_LIFETIME

# 3. Временный ключ на 30 дней:
python tools/license_server.py --create --sub "Client_Monthly" --hwid "GT-ABCD-1234-EF01" --plan DAY_PASS --days 30

# 4. Просмотр всех выданных лицензий:
python tools/license_server.py --list
```

### Б. Запуск REST API сервера
```bash
python tools/license_server.py --serve --port 8080
```
Сервер использует базу данных `tools/licenses.db` и предоставляет следующие эндпоинты:
* `POST /api/create_license` — создание и подпись лицензии (требует заголовок `X-API-Key`).
* `POST /api/webhook/payment` — вебхук автоматической генерации ключа после подтверждения оплаты.
* `GET /api/licenses` — список выданных лицензий.
* `GET /api/health` — проверка работоспособности сервиса.

## 3. Автоматизация выдачи ключей и приём онлайн-оплаты

### Способ А: Автовыдача из пакетного списка (без сервера)
1. Сгенерируйте партию ключей:
   ```bash
   python tools/license_generator.py --type lifetime --count 100 --output keys.txt
   ```
2. Загрузите список ключей в модуль автовыдачи платёжного шлюза или торговой площадки (Lava, Boosty, Digiseller, FunPay, Robokassa).
3. При покупке сервис автоматически выдаёт один ключ покупателю.

### Способ Б: Интеграция через REST API (`license_server.py`)
1. Запустите API-сервер:
   ```bash
   python tools/license_server.py --port 8080
   ```
2. Настройте вебхук успешной оплаты (Stripe, ЮKassa, Robokassa) на эндпоинт `POST /api/create_license`.
3. Сервер возвращает валидный токен, который отображается покупателю на странице подтверждения заказа.

### Защита от несанкционированной выдачи ключей на сайте
В файле [`website/src/lib/paymentConfig.ts`](../website/src/lib/paymentConfig.ts) реализована защита от бесплатной раздачи ключей:
* **Режим настройки (по умолчанию):**
  Пока параметры `isLivePaymentEnabled` или `paymentGatewayUrl` не заполнены, модальное окно оплаты информирует посетителя о том, что автоматический эквайринг настраивается, и предлагает оставить заявку либо связаться с администратором по email. Ключи бесплатно не выдаются.
* **Включение боевой оплаты:**
  Владелец указывает URL своего платёжного шлюза (Stripe Payment Link, Lava, Boosty, ЮKassa, Robokassa) и выставляет `isLivePaymentEnabled: true` (либо через переменные окружения `NEXT_PUBLIC_PAYMENT_ENABLED=true` и `NEXT_PUBLIC_PAYMENT_URL=https://...`). После этого покупатели автоматически перенаправляются на оплату.

## 5. Встроенные мастер-ключи (для тестирования)

Для проверки функционала в коде клиента предусмотрены мастер-ключи:
* `GHOST-VIP-PRO-2026` / `GHOSTVIPLIFETIME` — бессрочный доступ (**VIP Lifetime**)
* `GHOSTMONTHLY2026` / `GHOSTPROMONTHLY` / `GHOST30DAYSPASS` — подписка на 30 дней (**Pro Monthly**)
* `GHOST-DAY-1-PASS-2026` / `GHOST24HPASS` — суточный пропуск на 24 часа (**Day Pass**)
* `TRIAL-ACCESS-FREE` — пробный период на 3 дня (**Trial**)
* `COMMUNITYFREEACCESS` / `GHOSTFREECOMMUNITY` — бесплатный режим (**Community Edition**)
