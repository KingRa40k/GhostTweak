========================================================================
GhostTweak - Precompiled Release Binaries
========================================================================

This directory contains precompiled, production-ready binaries of GhostTweak:

1. GhostTweak_Portable.exe
   - Single-file standalone executable.
   - Does not require installation. Runs anywhere on Windows 10/11.

2. GhostTweak_Setup_v1.0.0.exe
   - Standard Windows installer (NSIS package).

3. GhostTweak_v1.0.0.msi
   - Enterprise MSI installer package for automated or silent deployment.

System Requirements:
------------------------------------------------------------------------
- OS: Windows 10 (version 1809 or higher) / Windows 11
- Architecture: 64-bit (x64)
- Runtime: Microsoft Edge WebView2 (preinstalled on modern Windows)
- Privileges: Run as Administrator (required for system/registry tweaks)

------------------------------------------------------------------------
How to Rebuild from Source:
------------------------------------------------------------------------
To rebuild binaries after making source code modifications, run:
  build.bat
from the project root directory. Newly built executables will be
automatically copied to this releases/ directory.
