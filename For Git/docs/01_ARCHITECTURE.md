# Архитектура и структура проекта GhostTweak

В данном документе описано устройство кодовой базы, используемый стек технологий и назначение каталогов проекта.

---

## 1. Стек технологий

| Модуль | Технологии | Назначение |
| :--- | :--- | :--- |
| **Ядро приложения** | Rust 2021, Tauri v2.2 | Прямой вызов Win32 API, таймер ядра (0.5 мс), замеры задержек, очистка кэшей, твики реестра |
| **Интерфейс приложения** | React 19, TypeScript, Tailwind CSS, Lucide Icons | Высокопроизводительный темный интерфейс (60+ FPS), динамические темы, мультиязычность |
| **Маркетинговый сайт** | Next.js 15 (App Router), React 19, Tailwind, Framer Motion | Презентация продукта, интерактивный макет, таблица сравнения, загрузка дистрибутивов |

---

## 2. Структура каталогов

```
valiant-maxwell/
├── build.bat                   # Скрипт сборки релиза в один клик
├── package.json                # Зависимости фронтенда десктопного приложения
├── releases/                   # Скомпилированные готовые дистрибутивы (.exe, setup, .msi)
├── scripts/                    # Вспомогательные скрипты упаковки
├── tools/                      # Утилиты лицензирования (license_generator.py, license_server.py)
├── src-tauri/                  # Бэкенд на Rust (Tauri v2)
│   ├── Cargo.toml              # Зависимости Rust (tauri, winreg, dirs, serde, walkdir)
│   ├── tauri.conf.json         # Конфигурация окна, бандла, прав доступа и CSP
│   ├── build.rs                # Скрипт линковки и компиляции манифеста Windows
│   └── src/
│       ├── main.rs             # Точка входа в процесс Windows
│       ├── lib.rs              # Инициализация плагинов, системного трея и регистрация команд
│       └── commands/           # Модули команд WinAPI:
│           ├── system_info.rs      # Сбор данных процессора, ОЗУ, видеокарты, частот монитора
│           ├── performance.rs      # Мультимедийный таймер ядра (0.5 мс), сброс RAM, DNS
│           ├── cleaner.rs          # Сканирование и очистка кэшей DirectX, NVIDIA, AMD, Temp
│           ├── tweaks.rs           # Твики реестра Win32, параметры CS2, DiagTrack
│           ├── backup.rs           # Экспорт и импорт веток реестра (.reg)
│           ├── security.rs         # Антиотладка, HWID-привязка, криптографическая валидация
│           └── window_controls.rs  # Управление окном и сворачивание в трей
├── src/                        # Фронтенд десктопного приложения (React 19)
│   ├── App.tsx                 # Корневой лейаут приложения, инициализация безопасности и темы
│   ├── main.tsx                # Точка монтирования React DOM
│   ├── pages/                  # Экраны приложения:
│   │   ├── Dashboard.tsx       # Главная панель мониторинга и быстрая оптимизация
│   │   ├── Cleaner.tsx         # Сканер мусора с выбором категорий
│   │   ├── Tweaks.tsx          # Твики реестра с тумблерами и категориями
│   │   ├── GameOptimizer.tsx   # Профиль CS2, замеры задержки, таймер ядра и DNS
│   │   ├── Profiles.tsx        # Сценарные профили (Esports, AAA, Streamer, Battery)
│   │   ├── Backups.tsx         # Менеджер точек отката реестра (.reg)
│   │   ├── Settings.tsx        # Настройки, язык, цветовая схема, поддержка
│   │   └── AuthScreen.tsx      # Экран активации лицензии
│   ├── components/             # Переиспользуемые компоненты (TitleBar, Sidebar, Modal и др.)
│   ├── lib/                    # Вспомогательные модули (tauri.ts, license.ts, i18n.tsx, theme.ts)
│   └── styles/                 # Стили Tailwind и анимации

    │   ├── components/         # Секции сайта (Hero, AppMockup, CoreArsenal, Pricing, FAQ)
```

## 3. Взаимодействие фронтенда и ядра

1. Пользователь выполняет действие в интерфейсе React (например, включает таймер 0.5 мс или запускает очистку кэша).
2. Фронтенд вызывает функцию `invoke('command_name', { args })` через модуль [`src/lib/tauri.ts`](../src/lib/tauri.ts).
3. Tauri транслирует вызов в соответствующий обработчик в `src-tauri/src/commands/`.
4. Rust-ядро выполняет вызов Win32 API с повышенными привилегиями и возвращает результат или структурированную ошибку.
5. Интерфейс React обновляет состояние без перезагрузки.
