# Часто задаваемые вопросы и решение проблем (FAQ & Troubleshooting)

Технические вопросы и рекомендации по устранению типовых ошибок при разработке, сборке и эксплуатации GhostTweak.

---

## 1. Зачем приложению требуются права администратора?

GhostTweak взаимодействует с системными параметрами Windows:
* Мультимедийный системный таймер (0.500 мс) через вызов `timeBeginPeriod`.
* Твики раздела реестра `HKEY_LOCAL_MACHINE` (отключение фоновой телеметрии DiagTrack, отключение задержек Nagle в стеке TCP/IP).
* Очистка системных каталогов `C:\Windows\SoftwareDistribution\Download` и `C:\Windows\Temp`.

Для этих действий Windows требует подтверждения контроля учётных записей (UAC).

---

## 2. Поведение Windows SmartScreen при первом запуске

Свежескомпилированные исполняемые файлы без коммерческого сертификата EV Code Signing могут помечаться фильтром Windows SmartScreen как «Неизвестный издатель».
* Для запуска достаточно нажать *«Подробнее»* -> *«Выполнить в любом случае»*.
* По мере использования и загрузок файла SmartScreen накапливает репутацию и перестает выводить уведомление.
* При наличии собственного сертификата подпись накладывается через `signtool.exe` (настройка описана в `docs/02_BUILD_AND_RELEASE.md`).

## 3. Ошибка сборки: «link.exe not found» или ошибки компоновщика MSVC

**Причина:**
Отсутствуют компоненты компилятора C++ и Windows SDK.

**Решение:**
1. Запустите Visual Studio Installer.
2. Включите рабочий набор «Разработка классических приложений на C++».
3. Убедитесь в наличии компонентов:
   * *MSVC v143 — средства сборки C++*.
   * *Пакет Windows 10/11 SDK*.
4. Перезапустите терминал и выполните сборку заново (`build.bat`).

---

## 4. Механизм резервного копирования и отката изменений

В модуле [`src-tauri/src/commands/backup.rs`](../src-tauri/src/commands/backup.rs) реализован откат изменений реестра:
* Перед изменением любого ключа GhostTweak экспортирует исходное состояние ветки в `.reg` файл с временной меткой в каталог `%APPDATA%\GhostTweak\backups\`.
* В разделе «Резервные копии» пользователь может восстановить исходные значения реестра в один клик.
